Dig-AI-FTE Project Overview - Autonomous Skill Dispatcher

Project Introduction

DIG-AI-FTE (Digital AI - Full-Time Equivalent) is an autonomous AI employee system that combines automated workspace monitoring with intelligent skill dispatch capabilities. The system features Human-in-the-Loop (HITL) approval for high-risk operations, ensuring safety while maintaining autonomous operation for routine tasks.

Built using Python 3.11+ with production-grade infrastructure (PM2 process management, atomic state management, comprehensive logging), the system follows Spec-Driven Development (SDD) principles and provides real-time CEO dashboard tracking via Obsidian integration.
