Dig-AI-FTE Project Overview

Project Introduction

This project implements an Automated Workspace Observer system that monitors the /specs directory for changes in real-time. When specification files are created, modified, or deleted, the system automatically updates corresponding Kanban cards in Factory_Board.md and updates the SDD tracker in SDD_Tracker.md based on YAML metadata.

The system is built using Python 3.11+ with the watchdog library for efficient file monitoring and follows Spec-Driven Development (SDD) principles. It operates as a background service providing continuous monitoring without manual intervention.

Key Features

Real-time File Monitoring

Uses Python's watchdog library to monitor the /specs directory for file creation, modification, and deletion events in real-time.

Automated Kanban Updates

Automatically updates Factory_Board.md Kanban cards when spec files change, keeping the visual board in sync with actual project state.

SDD Tracker Synchronization

Updates SDD_Tracker.md based on YAML metadata from spec files, maintaining status and percentage information.

Background Service Operation

Runs continuously as a background service without requiring manual restarts or interventions.

Alphabetical Processing Order

Processes multiple simultaneous file changes in alphabetical order by filename for predictable behavior.

Error Recovery & Resilience

Implements graceful error handling and recovery mechanisms for file system issues and temporary errors.
